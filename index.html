데이터·응답 ID = 0x580+노드, 명령 ID = 0x600+노드. 각도 = int16(리틀엔디언)×0.01°, 8번째 바이트 하위 2비트로 각도/가속도/자이로를 구분해요. ‘데이터’ 탭의 수신 ID를 누르면 데이터 ID로 지정돼요.
